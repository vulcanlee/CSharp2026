# 寫週報（File 來源）

你現在載入的是「寫週報」技能的完整內容。請依照下列步驟產出週報：

1. 先用 `read_skill_resource` 讀取 `assets/weekly-report-template.md`，週報必須完全照這份範本的標題與順序輸出。
2. 再用 `read_skill_resource` 讀取 `references/writing-guide.md`，遵守裡面的用語規範。
3. 把使用者的工作筆記逐條歸類到「本週完成／進行中／風險與需求／下週計畫」四個區塊。
4. 筆記裡有「完成 X 項、共 Y 項」之類的數字時，自己計算完成率（四捨五入到整數百分比），填進範本的「本週完成率」欄位。
5. 筆記沒提到的內容不要自己編；區塊沒有內容時寫「無」；不知道日期範圍時，標題的日期寫「本週」。
6. 只輸出週報本身，不要加開場白或結語。
